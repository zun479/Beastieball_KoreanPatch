Beastieball 비공식 한국어 패치 v0.1
=====================================

[번역 범위]
- 메인 화면·메뉴, 설정, 튜토리얼 설명, 도감 화면: 번역 완료
- 초반 스토리 대사 일부: 번역
- 나머지 대사·게임 데이터: 영어 원문으로 표시됨

[필요한 것]
- UndertaleModTool 0.9.2.0 이상 (Windows용 zip, SingleFile 아님)
  https://github.com/UnderminersTeam/UndertaleModTool/releases

[설치 순서]
1. 게임 폴더를 엽니다.
   Steam 라이브러리 > Beastieball 우클릭 > 관리 > 로컬 파일 탐색
2. data.win 파일을 복사해서 같은 폴더에 data.win.bak 으로 백업합니다.
3. 이 패치의 loc\한국어.csv 를 게임 폴더의 loc 폴더에 넣습니다.
4. 이 패치의 korean_font_patch 폴더를 게임 폴더에 통째로 넣습니다.
5. UndertaleModTool 실행 > File > Open > 게임 폴더의 data.win 을 엽니다.
   (YYC 경고 창이 뜨면 "확인"을 누르면 됩니다)
6. Scripts > Run other script... > korean_font_patch\ApplyKoreanFont.csx 선택
7. "Done! ftTextCN now has 5183 glyphs." 메시지가 뜨면 File > Save 로 저장합니다.
8. 게임 실행 > 설정 > 언어 > 한국어 선택 후 게임을 재시작합니다.

[게임이 업데이트되면]
- 업데이트 후 한글이 다시 빈칸으로 보이면 5~7번(폰트 패치)만 다시 하면 됩니다.
- 게임 구조가 바뀌면 스크립트가 오류 메시지를 띄우고 멈춥니다. 이 경우 패치 업데이트를 기다려 주세요.

[되돌리기]
- data.win 을 지우고 data.win.bak 의 이름을 data.win 으로 바꿉니다.
- 또는 Steam > 속성 > 설치된 파일 > 게임 파일 무결성 확인
